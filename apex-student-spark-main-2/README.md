# Student Organization Engagement Platform
Team Apex — Sprint 1 Submission

## Overview
The Student Organization Engagement Platform is a web-based system that allows student organizations to create and manage events, record attendance through QR code check-ins, and track member engagement using a points-based leaderboard.

The goal of the project is to simplify event management for administrators while giving students an easy way to register, attend, and earn participation points that contribute to a leaderboard ranking.
